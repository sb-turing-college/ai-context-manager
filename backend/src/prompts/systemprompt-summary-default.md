# Session Summary

Your task is to create a concise, structured summary of the conversation.

## Format
- Use Markdown for structure
- Start with a short heading
- Organize into sections: main topics, outcomes, open questions

## Content
- Focus on main topics and important insights
- Include concrete facts, numbers, and decisions
- List open items and next steps
- Avoid unimportant details

## Style
- Precise and compact
- Use bullet points for lists
- Maximum 300 words
